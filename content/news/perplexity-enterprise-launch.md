Perplexity AI has launched Perplexity Enterprise, bringing its AI-powered search to businesses with internal knowledge base integration.

## Key Enterprise Features

### Internal Knowledge Search
Connect your company's documents to Perplexity:
- Google Drive integration
- Confluence and Notion sync
- SharePoint connectivity
- Custom document uploads

Ask questions that search both the web AND your internal docs simultaneously.

### Security & Compliance
- **SOC 2 Type II** certified
- **SSO** via SAML 2.0 and OIDC
- Data isolation guarantees
- Audit logging
- Custom data retention

### Admin Controls
- User management dashboard
- Usage analytics
- Access controls by team
- Centralized billing

## Pricing

| Plan | Price | Features |
|------|-------|----------|
| Pro | $20/user/mo | Web search, basic |
| Enterprise | $40/user/mo | Internal docs, SSO, compliance |
| Enterprise+ | Custom | Dedicated support, custom integrations |

## Comparison with ChatGPT Enterprise

| Feature | Perplexity Enterprise | ChatGPT Enterprise |
|---------|----------------------|-------------------|
| Real-time web search | Yes (core feature) | Limited |
| Source citations | Always provided | Inconsistent |
| Internal docs | Yes | Yes |
| Price | $40/user | ~$60/user |

## Early Adopters

Companies already using Perplexity Enterprise:

## What This Means

Perplexity is positioning itself as the enterprise answer engine, distinct from ChatGPT's general-purpose assistant model. For research-heavy teams, the real-time web search and citation model may be compelling.
