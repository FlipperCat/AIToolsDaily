Anthropic has announced Claude Enterprise, a new tier designed specifically for large organizations with stringent security and compliance requirements.

## Key Enterprise Features

### Security & Compliance
- **SOC 2 Type II certification**
- **HIPAA eligibility** for healthcare organizations
- **GDPR compliance** with EU data handling
- **Data isolation** - your data never trains models
- **Audit logs** for all interactions

### Administration
- **Single Sign-On (SSO)** via SAML 2.0
- **Role-based access control**
- **Usage analytics dashboard**
- **Centralized billing**
- **Custom data retention policies**

### Enhanced Capabilities
- **500K token context window** (2x standard)
- **Priority API access** with guaranteed uptime SLA
- **Dedicated support** with 4-hour response times
- **Custom fine-tuning** options (limited availability)

## Pricing Structure

Claude Enterprise uses custom pricing based on:
- Number of seats
- API usage volume
- Support level required
- Compliance needs

Anthropic hasn't published specific numbers, but sources indicate starting costs around $30-50 per user per month for teams over 100 users.
