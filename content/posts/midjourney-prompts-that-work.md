## Key Parameters Explained

| Parameter | Effect |
|-----------|--------|
| --ar 16:9 | Widescreen (banners, headers) |
| --ar 1:1 | Square (social media, products) |
| --ar 2:3 | Portrait orientation |
| --ar 9:16 | Stories/mobile vertical |
| --v 6 | Latest Midjourney version |
| --style raw | Less "Midjourney look" |
| --stylize 50-200 | Control artistic interpretation |

## Pro Tips

1. **Be specific about lighting:** "soft natural light through window" beats "good lighting"
2. **Name reference styles:** "Architectural Digest style" or "National Geographic style"
3. **Include camera terms:** "shallow depth of field," "35mm lens," "f/1.8"
4. **Specify what you don't want:** Use --no [element] to exclude things
5. **Iterate:** Start simple, add details, refine
