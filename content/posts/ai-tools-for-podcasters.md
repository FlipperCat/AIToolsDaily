# AI Tools for Podcasters: The Complete Stack

Running a podcast takes too much time. Here's how AI can help.

## The Podcaster's AI Stack

| Task | Tool | Monthly Cost |
|------|------|--------------|
| Recording | Riverside/Squadcast | $15-29 |
| Transcription | Descript/Otter | $10-24 |
| Editing | Descript/Adobe Podcast | $12-24 |
| Show notes | ChatGPT/Claude | $0-20 |
| Social clips | Opus Clip/Vidyo | $0-25 |
| Enhancement | Adobe Podcast/Auphonic | $0-11 |

## Transcription

### Descript

**Cost:** $12-24/month

**What it does:**
- Transcribes audio with speaker labels
- Edit audio by editing text
- Remove filler words automatically
- Export clean transcripts

**Accuracy:** 95%+ for clear audio

**Best for:** Podcasters who want transcription + editing in one tool

### Otter.ai

**Cost:** Free tier / $10-20/month

**What it does:**
- Real-time transcription
- Speaker identification
- Searchable archive
- Collaboration features

**Accuracy:** 90-95%

**Best for:** Interview-heavy podcasts, quick transcripts

### Whisper (OpenAI)

**Cost:** Free (self-hosted) / API pricing

**What it does:**
- Highly accurate transcription
- Multiple languages
- Can run locally

**Accuracy:** 95%+

**Best for:** Tech-savvy podcasters, batch processing

## Audio Editing

### Descript

**The killer feature:** Edit audio by editing text.

**How it works:**
1. Import audio
2. See transcript
3. Delete text = delete audio
4. Move text = move audio

**Also does:**
- Filler word removal
- Studio Sound enhancement
- Overdub (fix mistakes with AI voice clone)
- Screen recording

**Why podcasters love it:**
Editing an hour episode goes from 3 hours to 1 hour.

### Adobe Podcast

**Cost:** Free (basic) / Part of Creative Cloud

**Key features:**
- Enhance Speech (removes noise, levels audio)
- Mic Check (audio quality suggestions)
- Transcription

**Best for:** Quick enhancement of audio quality

**The Enhance Speech tool:** Upload any audio, get studio-quality output. Genuinely impressive.

### Auphonic

**Cost:** Free tier / €9/month

**What it does:**
- Automatic leveling
- Noise reduction
- Loudness normalization
- Multi-track mixing

**Best for:** "Set it and forget it" post-production

## Show Notes and Content

### ChatGPT/Claude for Show Notes

**The workflow:**

1. Get transcript from Descript/Otter
2. Paste into ChatGPT with prompt:

```
Create podcast show notes from this transcript:

[Paste transcript]

Include:
- Episode summary (2-3 sentences)
- Key topics covered (bullet points)
- Guest bio if applicable
- Key quotes (3-5 notable quotes)
- Resources mentioned
- Timestamps for major topics

Format for WordPress/blog post.
```

3. Edit and polish
4. Publish

**Time saved:** 30-45 minutes per episode

### Blog Posts from Episodes

```
Turn this podcast transcript into a blog post:

[Paste transcript]

Make it:
- Readable (not just transcript format)
- SEO-friendly
- Include headers
- 1000-1500 words
- Add call to action at end

Topic: [Main topic of episode]
Target keyword: [Your keyword]
```

### Social Media Content

```
Create social media posts from this podcast episode:

[Paste key points or transcript]

Create:
- 3 Twitter/X posts (with hooks)
- 1 LinkedIn post
- 1 Instagram caption
- 5 potential quote graphics

Voice: [Your brand voice]
```

2. Upload audio

## The Production Workflow

### My Optimized Process

**Recording (1 hour):**
1. Record in Riverside (cloud backup, separate tracks)
2. Krisp running for noise cancellation

**Post-Production (45 minutes - was 2+ hours):**
1. Import to Descript
2. AI removes filler words
3. Edit via transcript
4. Apply Studio Sound
5. Export audio + transcript

**Content Creation (20 minutes - was 1+ hour):**
1. Feed transcript to ChatGPT
2. Generate show notes, blog post, social
3. Quick edit pass
4. Publish

**Clips (15 minutes - was 45+ minutes):**
1. Run through Opus Clip
2. Review and select best
3. Schedule for social

**Total time saved per episode:** 2-3 hours

## Detailed Tool Workflows

### Descript Full Workflow

**Setup:**
1. Import audio/video
2. Wait for transcription
3. Review for errors

**Editing:**
1. Read transcript
2. Highlight and delete unwanted sections
3. Use "Remove Filler Words"
4. Use "Shorten Word Gaps"
5. Apply Studio Sound

**Export:**
1. Export audio (MP3/WAV)
2. Export transcript (for show notes)
3. Export video (if applicable)

### Show Notes Workflow

**Step 1:** Get clean transcript from Descript

**Step 2:** Open Claude/ChatGPT

**Step 3:** Use this master prompt:

```
You're creating show notes for a podcast.

Episode title: [Title]
Guest: [Name] (if applicable)
Episode number: [Number]

Transcript:
[Paste transcript]

Create:

1. EPISODE SUMMARY
Write 2-3 sentences summarizing what listeners will learn.

2. TOPICS COVERED
- Bullet point for each major topic
- Include brief description

3. TIMESTAMPS
[MM:SS] - Topic name
(Estimate timestamps based on transcript position)

4. KEY QUOTES
Pull 3-5 memorable quotes with speaker attribution.

5. RESOURCES MENTIONED
List any tools, books, websites, etc. mentioned.

6. ABOUT THE GUEST
Brief bio (2-3 sentences).

7. CONNECT
[Where to find guest]
[Where to find podcast]

Format cleanly for blog/website.
```

**Step 4:** Light editing, add links, publish

## What AI Can't Do

### Creative Direction
AI won't tell you what topics matter or what your unique angle is.

### Guest Rapport
Building relationships that land great guests is human work.

### Authentic Voice
Your personality, opinions, and style can't be generated.

### Community Building
Engaging with listeners, building relationships - still requires you.
