Good prompts get good results. Here are 50 templates you can copy, customize, and use immediately.

## Writing and Content

### 1. Blog Post Outline
```
Create an outline for a blog post about [topic].
Target audience: [describe audience]
Tone: [casual/professional/educational]
Include: Introduction, 5-7 main sections, conclusion
```

### 2. Email Draft
```
Write an email to [recipient type].
Purpose: [what you want to achieve]
Context: [relevant background]
Tone: [formal/casual/urgent]
Length: [short/medium/detailed]
```

### 3. Social Media Post
```
Write a [platform] post about [topic].
Goal: [engagement/information/promotion]
Include: [hashtags/emoji/call-to-action]
Character limit: [number]
Brand voice: [describe]
```

### 4. Product Description
```
Write a product description for [product].
Target customer: [describe]
Key features to highlight: [list 3-5]
Tone: [aspirational/practical/luxury]
Length: [number] words
```

### 5. Rewrite for Clarity
```
Rewrite this text to be clearer and more concise:
[paste text]
Maintain the core message but simplify the language.
```

## Professional Communication

### 6. Meeting Request
```
Draft an email requesting a meeting.
With: [person/role]
Purpose: [reason]
Suggested times: [options]
Duration needed: [time]
My context: [brief background]
```

### 7. Status Update
```
Write a project status update.
Project: [name]
Progress since last update: [list]
Blockers: [any issues]
Next steps: [planned actions]
Audience: [stakeholders]
```

### 8. Feedback Delivery
```
Help me give constructive feedback.
Situation: [what happened]
Impact: [why it matters]
Desired change: [what should happen]
Tone: [supportive but direct]
```

### 9. Decline Request Gracefully
```
Help me decline [request type].
Reason: [why declining]
Relationship: [context with requestor]
Alternative to offer: [if any]
Tone: [apologetic/firm/grateful]
```

### 10. Follow-Up Email
```
Write a follow-up email.
Original context: [what it's about]
Days since last contact: [number]
Goal: [what you want]
Tone: [persistent but respectful]
```

## Analysis and Research

### 11. Summarize Document
```
Summarize this document in [number] bullet points:
[paste document]
Focus on: [key aspects to capture]
Audience: [who will read summary]
```

### 12. Compare Options
```
Compare these options: [list options]
Criteria: [factors that matter]
Context: [my situation]
Format: Table with pros/cons
Recommend: [yes/no - whether to give recommendation]
```

### 13. Extract Key Points
```
From this text, extract:
1. Main arguments
2. Key facts/statistics
3. Conclusions
4. Potential weaknesses
[paste text]
```

### 14. Research Summary
```
Summarize what I need to know about [topic].
My purpose: [why I need to know]
My background: [relevant knowledge level]
Format: [bullet points/paragraphs]
Focus on: [specific aspects]
```

### 15. SWOT Analysis
```
Create a SWOT analysis for [subject].
Context: [relevant background]
Industry: [if applicable]
Focus areas: [specific concerns]
```

## Problem Solving

### 16. Break Down Problem
```
I'm facing this problem: [describe]
Help me:
1. Identify root causes
2. List possible solutions
3. Evaluate tradeoffs
4. Recommend next steps
```

### 17. Devil's Advocate
```
Here's my plan: [describe]
Play devil's advocate:
- What could go wrong?
- What am I not seeing?
- What assumptions might be wrong?
- What would critics say?
```

### 18. Decision Framework
```
Help me decide between [options].
My priorities: [rank what matters]
Constraints: [limitations]
Timeline: [when I need to decide]
Risk tolerance: [low/medium/high]
```

### 19. Brainstorm Solutions
```
I need ideas for [goal].
Constraints: [limitations]
Already considered: [options rejected]
Give me 10 ideas ranging from safe to creative.
```

### 20. Root Cause Analysis
```
This problem keeps happening: [describe]
What I've tried: [past solutions]
Help me identify the underlying cause, not just symptoms.
```

## Learning and Explanation

### 21. Explain Concept
```
Explain [concept] to me.
My background: [relevant knowledge]
Purpose: [why I need to understand]
Style: [analogies/examples/technical]
Depth: [overview/detailed]
```

### 22. Study Guide
```
Create a study guide for [topic].
Exam/purpose: [context]
Time available: [how long to study]
Format: [flashcards/outline/practice questions]
```

### 23. ELI5 (Explain Like I'm 5)
```
Explain [complex topic] in the simplest possible terms.
Use analogies and everyday examples.
Avoid jargon completely.
```

### 24. Compare and Contrast
```
Explain the difference between [A] and [B].
Context: [why I'm comparing]
Focus on: [specific aspects]
Level: [beginner/intermediate/expert]
```

### 25. Quiz Me
```
Quiz me on [topic].
Difficulty: [easy/medium/hard]
Format: [multiple choice/short answer/both]
Number of questions: [number]
Give feedback after each answer.
```

## Meta-Prompts

### 46. Improve My Prompt
```
I'm trying to get AI to [goal].
Here's my current prompt: [paste]
What's missing or unclear?
How would you improve it?
```

### 47. Role Assignment
```
You are a [expert type] with [X] years of experience in [field].
Approach this like you're advising a colleague.
Be specific and actionable.
```

### 48. Output Format
```
[Your request]
Format your response as:
- [Specify: bullets/table/numbered list/JSON]
- [Length: brief/detailed]
- [Include: specific elements]
```

### 49. Iteration Request
```
That's good, but:
- Make it more [specific quality]
- Less [quality to reduce]
- Add [missing element]
- Remove [unnecessary element]
```

### 50. Context Setting
```
Context:
- I am a [your role]
- Working on [project type]
- For [audience/client]
- Goal is [objective]

With this context, help me [specific request].
```

## How to Use These Templates

1. **Copy the template**
2. **Fill in the [brackets]**
3. **Delete any irrelevant lines**
4. **Add specific details**
5. **Iterate on the result**

Better prompts = better results. Use these as starting points, then customize for your specific needs.
