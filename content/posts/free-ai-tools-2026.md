## Writing and Content

### ChatGPT Free (OpenAI)

**What it does:** General-purpose AI assistant for writing, analysis, coding, research.

**What's free:**
- Unlimited usage
- GPT-4o (latest model)
- All basic features
- Web search (limited)

**What's limited:**
- Slower response times than Plus
- No file uploads for data analysis
- No voice or image input

**Best for:** Email writing, blog outlines, brainstorming, customer service responses, coding help.

**Cost:** $0

### Google Gemini Free

**What it does:** Google's AI assistant powered by Gemini models.

**What's free:**
- Unlimited usage
- Recent model (Gemini 2.0)
- Deep Google integration
- Image input and output

**Best for:** Research (Google has real-time web search), Gmail integration, summarizing documents, visual analysis.

**Cost:** $0

### Claude Free (Anthropic)

**What it does:** AI assistant strong in writing, analysis, and long-document handling.

**What's free:**
- Limited usage (messages reset monthly)
- Latest Claude model
- Document upload and analysis
- 200K context window

**What's limited:**
- Monthly message cap (typical free users get 30-50 messages daily)
- Slower than paid version
- File upload limits

**Best for:** Document analysis, long-form writing, detailed explanations, creative writing.

**Cost:** $0
