# Bing Chat vs Bard (2023): Which Free AI Chatbot Should You Use?

Microsoft and Google are now both giving away AI chatbots for free, and both are tied to the search engines they run. Bing Chat runs on OpenAI's GPT-4 and has been open to anyone with a Microsoft account since early May. Bard dropped its waitlist at Google I/O, switched to the new PaLM 2 model, and expanded to more than 180 countries.

If you're not paying for ChatGPT Plus, these two are the most capable free options available. They behave quite differently, though. We used both for several weeks of everyday research, writing, and coding tasks. Here's where each one wins.

## Quick Comparison Table

| Dimension | Bing Chat | Bard |
|-----------|-----------|------|
| Underlying model | GPT-4 (Microsoft's customized version) | PaLM 2 |
| Price | Free with a Microsoft account | Free with a Google account |
| Web access | Yes, Bing search results with footnote citations | Yes, Google search, but citations are inconsistent |
| Response speed | Slower, especially in Creative mode | Noticeably faster |
| Conversation limits | Capped turns per conversation | No hard per-chat cap we hit |
| Best browser | Microsoft Edge (sidebar integration) | Any browser |
| Image generation | Yes, via Bing Image Creator (DALL-E) | No |
| Multiple drafts | No, though you can switch tone mode | Yes, view other drafts |
| Export options | Copy, share | Export to Gmail and Docs, code to Colab |
| Availability | Broad, including the EU | 180+ countries, but not the EU or Canada yet |

## Answer Quality and Reasoning

On tasks that need careful reasoning, like multi-step logic, nuanced explanations, and tricky edge cases, Bing Chat usually comes out ahead. That's expected given it's built on GPT-4, the same model that powers the paid tier of ChatGPT. Ask it to explain why a contract clause might be ambiguous or to compare two investment approaches, and you'll get a more structured, careful answer.

Bard has improved quickly since its rocky March launch. The move to PaLM 2 made it clearly better at reasoning and coding than the original model. Google also says a June update improved its math and logic by having it quietly write and run code behind the scenes for certain questions. It's still more likely than Bing to state something confidently wrong, especially on niche facts.

**Edge:** Bing Chat, for anything where accuracy matters more than speed.

## Research and Citations

This is Bing Chat's strongest point. Nearly every factual answer comes with numbered footnotes that link to the pages it pulled from, so you can verify claims in one click. Its three conversation styles also help:

- **Precise** sticks closely to search results and gives shorter answers. Use it for fact-finding.
- **Balanced** is the default and works for most tasks.
- **Creative** gives longer, more imaginative answers. It's better for brainstorming and worse for facts.

Bard pulls from Google Search too, and it's usually more current on fast-moving topics. It rarely shows where its information came from, though. There's a "Google it" button that suggests related searches, which helps, but it isn't the same as inline citations. When we asked both tools about recent product announcements, Bard was often faster and more up to date, while Bing was easier to fact-check.

If research is your main use case, it's worth looking at how a citation-first tool like Perplexity handles the same queries. Our [Bard vs ChatGPT comparison](/compare/bard-vs-chatgpt-2023/) also covers how Bard holds up against a chatbot with no live web access at all.

**Edge:** Bing Chat for verifiable research. Bard for quick, current answers when you don't need sources.

## Writing and Drafting

Both handle emails, outlines, summaries, and social posts well. The workflows differ.

Bard's **drafts** feature is underrated. Each response comes with alternative versions you can flip between, so it's easy to pick the best opening line or tone without re-prompting. The **export to Gmail and Google Docs** buttons are a real time-saver if you already live in Google Workspace. Draft an email in Bard and send it straight to a Gmail draft.

Bing Chat writes slightly more polished long-form prose, especially in Creative mode. The Edge sidebar also has a dedicated Compose panel where you pick tone, format, and length, which is handy for quick drafts. The turn limit per conversation gets in the way during long editing sessions, though. Once you hit it, you have to start over and lose context.

**Edge:** Tie. Bard for Google users and fast iteration, Bing for more polished copy.

## Coding Help

Both can explain code, write functions, and debug simple errors. Bard added coding help in more than 20 languages in April and now lets you export Python code directly to Google Colab, which is great for data work and quick experiments.

Bing Chat's GPT-4 base gives it an edge on harder problems: tracking down a subtle bug, refactoring a messy function, or explaining an unfamiliar library. It's slower, and its web search sometimes pulls in outdated Stack Overflow answers, but the reasoning is generally sharper.

For serious coding work, a dedicated assistant is still the better tool. See our [GitHub Copilot vs ChatGPT for coding](/compare/github-copilot-vs-chatgpt-coding-2023/) comparison.

**Edge:** Bing Chat for difficult problems, Bard for quick snippets and Colab users.

## Images and Multimodal Features

Bing Chat can generate images right in the conversation using Bing Image Creator, which runs on an advanced version of OpenAI's DALL-E. Describe what you want and it returns four options. That's a real advantage. Bard can't generate images at all.

Bard has started showing relevant images from Google Search in some answers, which helps for things like travel planning or product questions. Google has also announced Google Lens integration so you can upload an image and ask about it. Microsoft has announced similar visual search for Bing Chat. As of this writing, neither has fully reached everyone, so we haven't factored them in.

**Edge:** Bing Chat, because it can generate images.

## Speed and Convenience

Bard is fast. Most answers appear in a few seconds, and the interface is clean and works the same in any browser.

Bing Chat is slower, particularly in Creative mode with long responses. It's also heavily tied to Microsoft Edge. The sidebar integration is genuinely useful there, since it can summarize the page you're reading. Using it outside Edge is more awkward, and the mobile experience runs through the Bing app. The per-conversation turn limit is the other big friction point. Microsoft has raised it a few times since launch, but you'll still hit it in long sessions.

**Edge:** Bard.

## Privacy and Data

Both companies store your conversations and may use them to improve their services, with some human review. Bard activity can be paused or deleted from your Google account settings. Bing Chat history is tied to your Microsoft account. Neither is appropriate for confidential business information, client data, or anything you wouldn't want reviewed. Treat both as public-facing tools.

## Availability

Bing Chat is available in most markets where Bing operates. Bard is available in more than 180 countries but notably not yet in the European Union or Canada. That alone decides it for many readers.

## Which Should You Choose?

**Choose Bing Chat if:**
- You want GPT-4 quality without paying $20/month for ChatGPT Plus
- You need citations you can check, for research, reports, or anything you'll publish
- You want to generate images in the same chat
- You already use Microsoft Edge

**Choose Bard if:**
- Speed matters more than depth
- You work in Gmail and Google Docs and want one-click export
- You like comparing multiple drafts of the same answer
- You want current information on fast-moving topics and can verify it yourself

**Our recommendation:** Use both. They're free, and they complement each other.
