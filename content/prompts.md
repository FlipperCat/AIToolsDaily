## Writing Prompts

### Blog Post First Draft
```
Write a blog post about [TOPIC].

Target audience: [WHO]
Tone: [professional/casual/technical]
Length: [X] words

Include:
- Compelling introduction with hook
- 3-5 main sections with H2 headers
- Actionable takeaways
- Conclusion with CTA

Do not use: "In today's world", "It's important to note", or other filler phrases.
```

### Email Newsletter
```
Write a weekly newsletter about [TOPIC].

Format:
- Subject line (under 50 characters, create curiosity)
- Opening hook (1-2 sentences)
- Main content (3 key points)
- CTA

Tone: Conversational, like writing to a smart friend.
Length: Under 500 words.
```

### LinkedIn Post
```
Write a LinkedIn post about [TOPIC].

Structure:
- Hook (first line that makes people click "see more")
- Story or insight (2-3 short paragraphs)
- Lesson or takeaway
- Engagement question

Use short paragraphs. No hashtags in the middle. Put 3-5 hashtags at the end only.
```

### Cold Email
```
Write a cold email to [PROSPECT TYPE].

I'm offering: [YOUR SERVICE/PRODUCT]
Their likely pain point: [PROBLEM]
My proof: [CREDIBILITY]

Rules:
- Under 100 words
- No "I hope this email finds you well"
- One clear CTA
- Sound human, not salesy
```

## Marketing Prompts

### Product Description
```
Write a product description for [PRODUCT].

Key features: [LIST]
Target customer: [WHO]
Price point: [PRICE]
Competitor comparison: [VS WHO]

Format:
- Headline (benefit-focused)
- 2-3 sentence overview
- 3-5 bullet points (features → benefits)
- Social proof placeholder
- CTA
```

### Ad Copy (Facebook/Google)
```
Write 5 ad variations for [PRODUCT/SERVICE].

Target audience: [WHO]
Main benefit: [WHAT]
Offer: [DISCOUNT/TRIAL/ETC]
Character limit: [X]

For each ad:
- Headline
- Primary text
- CTA

Make each variation different: emotional, logical, fear-based, aspirational, social proof.
```

### Landing Page Copy
```
Write landing page copy for [PRODUCT].

Sections needed:
1. Hero (headline + subheadline + CTA)
2. Problem (what pain does this solve?)
3. Solution (how does it work?)
4. Features (3-5 key features with benefits)
5. Social proof (placeholder for testimonials)
6. FAQ (5 common objections)
7. Final CTA

Tone: [BRAND VOICE]
Target: [AUDIENCE]
```

## Coding Prompts

### Code Review
```
Review this code for:
1. Bugs and potential issues
2. Performance problems
3. Security vulnerabilities
4. Code style and best practices
5. Suggestions for improvement

[PASTE CODE]

Format your response as:
- CRITICAL: [issues that must be fixed]
- WARNINGS: [issues that should be fixed]
- SUGGESTIONS: [nice-to-have improvements]
```

### Debug This Error
```
I'm getting this error:
[ERROR MESSAGE]

In this code:
[CODE]

Context:
- Language/framework: [X]
- What I was trying to do: [Y]
- What I've already tried: [Z]

Please:
1. Explain why this error occurs
2. Provide the fix
3. Explain how to prevent it in the future
```

### Generate Function
```
Write a [LANGUAGE] function that [DESCRIPTION].

Requirements:
- Input: [PARAMETERS]
- Output: [RETURN VALUE]
- Edge cases to handle: [LIST]
- Style: [any specific requirements]

Include:
- The function code
- Example usage
- Brief explanation of approach
```

## Business Prompts

### Competitor Analysis
```
Analyze [COMPETITOR] as a competitor to my business.

My business: [DESCRIPTION]
My target market: [WHO]

Analyze:
1. Their strengths (what they do well)
2. Their weaknesses (where they fall short)
3. Their positioning (how they present themselves)
4. Their pricing strategy
5. Gaps I could exploit
6. What I can learn from them

Be specific and actionable.
```

### Business Plan Section
```
Write the [SECTION] section of a business plan for [BUSINESS IDEA].

Context:
- Target market: [WHO]
- Business model: [HOW IT MAKES MONEY]
- Stage: [idea/MVP/growth]

Make it:
- Specific (not generic)
- Realistic (not overly optimistic)
- Investor-ready (if applicable)
```
