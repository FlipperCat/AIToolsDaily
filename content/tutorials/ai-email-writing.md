Writing emails takes more time than it should. Crafting the right tone, being concise, and avoiding misunderstandings requires thought.

AI can write your emails in seconds. Here's how to do it well.

## Basic Email Prompts

### Simple Request

**Prompt:**
```
Write a professional email asking my colleague Sarah to send me the Q4 sales report by Friday. Keep it brief and friendly.
```

**Output:**
> Hi Sarah,
>
> Hope you're doing well! Could you send me the Q4 sales report when you get a chance? I'd like to have it by Friday if possible.
>
> Thanks!
> [Your name]

### Following Up

**Prompt:**
```
Write a polite follow-up email. I sent a proposal to a client 5 days ago and haven't heard back. Don't be pushy.
```

**Output:**
> Hi [Name],
>
> Just wanted to check in on the proposal I sent over last week. I know you're busy, so no rush — but let me know if you have any questions or would like to discuss further.
>
> Happy to jump on a call whenever works for you.
>
> Best,
> [Your name]

### Declining Politely

**Prompt:**
```
Write an email declining a meeting request. I'm too busy this week but open to next week. Be professional but not cold.
```

**Output:**
> Hi [Name],
>
> Thanks for reaching out! Unfortunately, I'm fully booked this week and wouldn't be able to give our meeting the attention it deserves.
>
> Would sometime next week work for you? I'm generally free Tuesday and Thursday afternoons.
>
> Let me know what works!
>
> Best,
> [Your name]

## Advanced Prompts

### Setting Context

Better prompts give context:

```
I'm a freelance web developer. Write an email to a client who's asking for additional features beyond our original scope. I want to be helpful but also make clear this would require a change order. Keep it professional and maintain the relationship.
```

### Specifying Tone

Add tone instructions:

```
Write a firm but professional email to a vendor who delivered late. Tone: direct, not angry, focused on solutions.
```

```
Write a congratulations email to a team member on their promotion. Tone: warm, genuine, celebratory.
```

### Email Chains

For replies, paste the original email:

```
Reply to this email professionally. Agree to the meeting but suggest a different time:

[Paste original email here]
```

## Email Templates (Copy & Customize)

### Meeting Request

```
Write a meeting request email.
- Who: [Name], [their role]
- Purpose: [what you want to discuss]
- Duration: [15/30/60 minutes]
- Urgency: [high/normal/low]
- Your availability: [days/times]
```

### Project Update

```
Write a project update email.
- Recipient: [Name/team]
- Project: [name]
- Progress: [what's done]
- Blockers: [if any]
- Next steps: [what's coming]
- Help needed: [if any]
```

### Apology Email

```
Write a professional apology email.
- Situation: [what went wrong]
- Impact: [how it affected them]
- Fix: [what you're doing about it]
- Prevention: [how you'll avoid this in future]
- Tone: sincere but not groveling
```

### Sales Follow-Up

```
Write a follow-up email to a prospect.
- Context: [how you met / previous contact]
- Their pain point: [what problem they mentioned]
- Your solution: [how you help]
- Ask: [next step you want them to take]
- Tone: helpful, not salesy
```

## Best Practices

### 1. Always Edit

AI gives you a draft, not a finished email. Always:
- Check for accuracy
- Adjust tone to match your voice
- Verify names and details
- Remove anything too generic

### 2. Add Personal Touches

AI writes generic. Add specifics:
- Reference previous conversations
- Mention something personal (if appropriate)
- Include details only you would know

### 3. Match Your Voice

If AI writes more formally than you speak, adjust. Consistency builds trust.

### 4. Use for Structure, Not Just Text

Ask AI to outline complex emails:
```
Create an outline for an email explaining why we're raising prices. Include: acknowledgment of impact, reasons (costs increased), value we provide, timeline, how to contact with questions.
```

Then write it yourself using the structure.

### 5. Specify Length

AI tends to be wordy. Be explicit:
- "Keep it under 100 words"
- "Maximum 3 paragraphs"
- "Be concise — this person gets hundreds of emails"

### Copy-Paste Workflow

Simple but effective:
1. Open ChatGPT alongside email
2. Paste prompt + context
3. Copy response
4. Paste and edit in email client
5. Send

Takes 30 seconds for most emails.

## Common Mistakes

### 1. Sending Without Reading

AI makes mistakes. Names, facts, tone — always read before sending.

### 2. Being Too Generic

"I hope this email finds you well" is obvious AI. Personalize.

### 3. Over-Relying on AI

Some emails need human thought. Sensitive topics, complex negotiations, relationship-building — write those yourself.

### 4. Wrong Tone for Context

Formal AI email to a close colleague feels weird. Match tone to relationship.

## Getting Started

1. Open ChatGPT (free)
2. Next email you need to write, paste this:
   ```
   Write a [type] email to [recipient]. Context: [situation]. Tone: [formal/casual/friendly]. Keep it [brief/detailed].
   ```
3. Edit the output
4. Send

Within a week, you'll develop your own prompts and cut email time dramatically.
