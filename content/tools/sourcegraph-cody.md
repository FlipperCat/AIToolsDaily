Cody combines Sourcegraph's powerful code search with AI to create an assistant that truly understands your codebase—not just the file you're editing.

## Context Is Everything

Cody leverages Sourcegraph's code intelligence:
- Searches across all repositories
- Understands code relationships
- Retrieves relevant context
- Answers with precision

## Key Features

- **Chat**: Ask questions about code
- **Commands**: Pre-built AI actions
- **Autocomplete**: Inline suggestions
- **Explain**: Understand complex code
- **Generate**: Create tests, docs

For organizations with large, complex codebases, Cody's ability to search and understand code across repositories makes it uniquely valuable. It can answer questions about code patterns, find examples, and suggest changes with full context.
