Grok is xAI's AI assistant, known for its wit and real-time access to X (Twitter) data.

## What is Grok?

Grok is an AI assistant built by xAI (Elon Musk's AI company). Its unique feature is integration with X, providing real-time access to tweets and trending topics.

## Key Features

### Real-Time X Data

Unique advantage:
- Access current tweets
- Trending topics
- Live events
- Social sentiment

### Personality

Distinctive style:
- Witty responses
- Humor included
- Rebellious tone
- Less filtered than competitors

### Image Understanding

Analyze images:
- Screenshot interpretation
- Image description
- Visual Q&A

### Image Generation

Create images:
- Built-in generation
- Various styles
- Quick creation

## Pricing

Grok is included with X Premium subscriptions:
- **Basic**: $8/month (Grok access)
- **Premium**: $8/month (more features)
- **Premium+**: $16/month (full access)

## Best Use Cases

- Understanding X trends
- Current events analysis
- Casual conversation
- Social media research
- Entertainment

| Feature | Grok | ChatGPT |

## Limitations

- X Premium required
- Capability behind GPT-4/Claude

Grok is best for X power users who want AI assistance with social media context.
