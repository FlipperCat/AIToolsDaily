Windsurf is Codeium's AI-native IDE that combines familiar VS Code foundations with powerful agentic AI capabilities.

## What is Windsurf?

Windsurf is a fork of VS Code rebuilt around AI-first principles. It features Cascade, an AI agent that can understand your entire codebase and make multi-file changes autonomously.

## Key Features

### Cascade AI

Agentic coding assistant:
- Plans multi-step changes
- Modifies multiple files
- Understands project context
- Executes terminal commands

### Codebase Intelligence

Deep understanding:
- Indexes entire project
- Semantic code search
- Dependency awareness
- Architecture understanding

### Flows

Guided AI workflows:
- Refactoring assistance
- Feature implementation
- Bug investigation
- Code review

### Privacy by Default

Codeium's privacy commitment:
- No code training
- Secure processing
- Enterprise compliance
- Self-hosted options
