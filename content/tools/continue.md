Continue is the open-source alternative that puts you in control. Use any AI model—local or cloud—and customize exactly how your coding assistant works.

## Model Freedom

Choose your AI provider:
- **Local**: Ollama, LM Studio, llama.cpp
- **Cloud**: OpenAI, Anthropic, Azure
- **Custom**: Any OpenAI-compatible API

## Key Features

- **Tab Autocomplete**: Inline suggestions
- **Chat**: Discuss code
- **Edit**: Modify selections
- **Context**: Add files, docs, URLs
- **Commands**: Custom slash commands

## Why Open Source Matters

- No vendor lock-in
- Full transparency
- Community contributions
- Self-hosting option
- Customize everything

## Getting Started

1. Install VS Code extension
2. Configure your model provider
3. Optionally run local models
4. Customize to your workflow

For developers who want AI assistance without giving up control or privacy, Continue offers the most flexible solution available.
