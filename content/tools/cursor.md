Cursor isn't just an AI coding assistant—it's a completely reimagined code editor with AI at its core. Built on VS Code, it maintains compatibility while adding powerful AI capabilities.

## Beyond Code Completion

Cursor's AI can:
- Understand your entire codebase
- Make changes across multiple files
- Debug by analyzing error messages
- Explain complex code sections
- Suggest architectural improvements

## Key Differentiators

- **⌘K**: AI edit any selection
- **Chat**: Discuss code with context
- **Composer**: Multi-file AI editing
- **@ Symbols**: Reference files/folders
- **Custom Rules**: Train AI on your patterns

## Cursor vs Copilot

While Copilot excels at inline suggestions, Cursor shines at larger-scale AI interactions—chat, multi-file edits, and codebase-wide understanding. Many developers use both.
