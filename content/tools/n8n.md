n8n is the automation tool for those who want control. Self-host it for free, keep your data on your servers, and customize workflows with JavaScript when the UI isn't enough.

## Fair-Code Model

n8n uses a "fair-code" license:
- Free to self-host
- Source code available
- Commercial cloud option
- Enterprise features paid

## Key Differentiators

- **Self-Hosting**: Run on your infrastructure
- **Code Nodes**: Write JavaScript/Python
- **Data Privacy**: Your data stays yours
- **Customization**: Extend with custom nodes
- **Cost Efficiency**: No per-operation limits

## Deployment Options

| Option | Price | Features |
|--------|-------|----------|
| Self-Hosted | Free | Everything, you manage |
| Cloud Starter | $20/mo | Managed hosting |
| Cloud Pro | $50/mo | More executions |
| Enterprise | Custom | Premium support |

## Who Should Use n8n?

If you're technical, value data privacy, or want to avoid per-operation costs, n8n is compelling. The self-hosted option means your automation costs are just your server costs, regardless of volume.
