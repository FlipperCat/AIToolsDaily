Lovable (formerly GPT Engineer) is an AI-powered platform that creates complete web applications from text descriptions.

## What is Lovable?

Lovable transforms natural language into working web applications. Unlike component generators, it builds full-stack apps with frontend, backend, authentication, and database—all deployable with one click.

## Key Features

### Text-to-App Generation

Describe what you want:
- "A project management app with kanban boards"
- "A booking system for a salon"
- "A SaaS dashboard with user accounts"

Lovable generates the complete application.

### Supabase Integration

Backend features built-in:
- User authentication
- Database with PostgreSQL
- Real-time updates
- File storage

### Iterative Development

Refine through conversation:
- "Add a dark mode toggle"
- "Change the dashboard layout"
- "Add email notifications"

### Deployment

One-click deployment includes:
- Hosting
- Custom domains
- SSL certificates
- CDN distribution
