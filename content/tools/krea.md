Krea AI is a creative AI platform featuring real-time image generation, enhancement, and various creative tools.

## What is Krea AI?

Krea AI offers multiple AI creative tools, with its signature feature being real-time image generation that updates as you type or draw.

## Key Features

### Real-Time Generation

Watch images form as you:
- Type prompts
- Draw sketches
- Modify inputs
- Adjust parameters

### Enhancer

Improve existing images:
- Upscale resolution (up to 4x)
- Add details
- Fix artifacts
- Sharpen quality

### Logo Illusions

Create images that form logos:
- Upload logo
- Choose style
- Generate integrated imagery

### Patterns

Create seamless patterns:
- Tileable designs
- Brand patterns
- Texture generation

### AI Canvas

Edit images with AI:
- Inpainting
- Outpainting
- Object removal
- Style transfer
