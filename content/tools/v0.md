v0 is Vercel's AI tool for generating user interfaces from text descriptions.

## What Makes v0 Stand Out?

Describe a component—"a pricing page with three tiers"—and get working React code using shadcn/ui and Tailwind CSS.

## Key Features

### Text-to-UI Generation

Describe your component and get code:
- "A dashboard with analytics cards"
- "A user settings page"
- "A modern hero section"

### Modern Stack

Built on shadcn/ui components, Tailwind CSS, and Radix UI primitives. Accessible by default.

### Iterative Refinement

Chat to refine: "Make buttons larger" or "Add dark mode support."
