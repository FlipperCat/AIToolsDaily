Mistral AI is a French AI company offering powerful, efficient language models with strong European values around data sovereignty.

## What is Mistral AI?

Mistral builds efficient language models that punch above their weight class. Their models offer competitive performance while being smaller and faster than competitors.

## Key Models

### Mistral Large

- Most capable model
- Competitive with GPT-4
- Best for complex reasoning
- Enterprise-ready

### Mistral Medium

- Balanced performance
- Good for most tasks
- Cost-effective
- Fast responses

### Mistral Small / Ministral

- Efficient for simple tasks
- Very fast
- Low cost
- Edge deployment

## Key Features

### Le Chat

Free chat interface:
- Access to Mistral models
- No subscription needed
- Web browsing
- Document analysis

### Open Weights

Available for download:
- Run locally
- Customize for needs
- No API dependency
- Full control

### API Access

Developer-friendly:
- Simple integration
- Competitive pricing
- Function calling
- Streaming support
