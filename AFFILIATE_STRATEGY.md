## How to Sign Up

### Zapier Partner Program
1. Go to: https://zapier.com/platform/partner-program
2. Apply as Content Partner
3. Get approved (usually 1-3 days)
4. Get unique tracking links

### Make.com Affiliate
1. Go to: https://www.make.com/en/affiliate
2. Sign up
3. Get tracking links from dashboard

### Impact Radius Programs (Jasper, etc.)
Many programs use Impact Radius:
1. Create Impact account: https://impact.com
2. Search for programs
3. Apply through the platform

### Individual Programs
For tools without affiliate programs:
1. Email them directly
2. Ask about partnership opportunities
3. Some will set up custom tracking for content creators

## Content → Affiliate Mapping

| Article Type | Best Affiliate Strategy |
|--------------|-------------------------|
| Reviews | Direct CTA to tool at bottom |
| Comparisons | Links to both tools, let user decide |
| Tutorials | Contextual links where tool is mentioned |
| List posts | Link each tool mentioned |

## Link Placement Best Practices

### Do:
- Place CTA boxes after key sections
- Use affiliate links in tool names
- Include comparison tables with links
- Add "Try [Tool] Free" buttons

### Don't:
- Overload with links (1-3 per 500 words)
- Link every mention of a tool
- Hide that links are affiliate (disclose!)
- Recommend tools you wouldn't use

## Tracking & Optimization

### Track These Metrics:
- Click-through rate per article
- Conversion rate per program
- Revenue per article
- Which CTAs perform best

### Optimize Based On:
- High-traffic articles → Add more affiliate links
- High-converting tools → Create more content about them
- Low-performing programs → Consider removing

## Disclosure Requirements

**FTC requires disclosure.** Every page with affiliate links should have:

1. General disclosure near top of article OR
2. Disclosure next to each affiliate link

Our template includes this in the frontmatter:
```yaml
affiliate_disclosure: true
```

This automatically adds the disclosure box at the bottom of articles.
